# Участие в проекте Housing Registry

Спасибо за интерес к проекту. Мы приветствуем сообщения об ошибках, предложения
по источникам данных, улучшения документации и pull request.

## Перед началом работы

1. Проверьте существующие Issues, чтобы не создавать дубликат.
2. Для существенного изменения сначала опишите задачу в Issue.
3. Не публикуйте пароли, токены, персональные данные, дампы БД и большие архивы.
4. Для нового источника укажите его владельца, публичный адрес, формат и условия
   использования.

## Локальная проверка

Если `.env` ещё нет, скопируйте `.env.example` в `.env` и замените заглушки
секретного ключа Django и пароля PostgreSQL. Django загружает `.env`
автоматически; переменные окружения имеют приоритет над файлом.

```bash
python3.12 -m venv .venv
./.venv/bin/python -m pip install -r requirements-dev.txt
./.venv/bin/python manage.py migrate
./.venv/bin/python manage.py check
./.venv/bin/python -m ruff check .
./.venv/bin/python -m pytest
./.venv/bin/python manage.py makemigrations --check --dry-run
```

Проверки используют PostgreSQL из `.env`; тестовому пользователю нужно право
создавать отдельную тестовую БД.

## Требования к изменениям

- миграции добавляются вместе с изменениями моделей;
- новая логика сопровождается тестами;
- структура и границы MVP-1 определены в `docs/mvp-1-spec.md`;
- исходные JSON в БД MVP-1 не сохраняются; тестовые ответы очищаются от секретов;
- частичная региональная выборка не должна изменять данные других регионов;
- изменения схемы или алгоритма импорта описываются в pull request.
